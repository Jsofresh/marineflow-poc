# UI Notes (Target users: Jessica / Service Managers / CEO)

## Principles
- Reduce cognitive load: fewer choices per screen.
- Always show "what should I do next".
- Use plain-language labels (avoid jargon).
- Make the happy path obvious; hide advanced options.

- Housecall Pro: plain language + obvious primary actions.
